# a letter that arrived late
Pure HTML/CSS/JS. Open `index.html` locally (or `python3 -m http.server`) to test.

Edit only:
- `js/config.js` : dates, photos, song, gallery
- `js/content.js`: all chapter text

Put images/audio in `assets/`. Use audio you have rights to, or keep `song.src` empty
and the page links to the official listening page instead.

Deploy: push to GitHub > Settings > Pages > Deploy from branch (main / root).
